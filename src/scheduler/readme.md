# 구현 계획
object dection 결과를 토대로 산정한 점수를 입력받아
화면에 출력할 2개의 device를 선택

주기마다 dection 결과를 바탕으로 점수 산정 후 scheduler로 전송(mock)
송신한 점수를 바탕으로 주기마다 화면에 출력되는 device 갱신

## 설계 목적
### 점수 산정 알고리즘 분리
object dection 모델에 따라 감지 가능한 개체와 빈도가 다르기 떄문에 점수 산정 알고리즘이 모델에 의존성을 갖는다고 생각하여 분리하였습니다.

### 스케쥴러 화면을 일정 시간마다 전환
새로운 객체를 검출할때마다 화면을 전환할 경우 너무 잦은 화면전환으로 사람이 관측하기 어려운 상황이 발생할 수 있으므로, 일정 시간을 기준으로 전환하는 것이 사람이 관측하기에 적합하다고 생각하였습니다.

### 입출력 정의
#### 입력
device별로 산정된 점수
#### 출력
deviceId 2개
### 제외 조건
사용자가 고정한 device는 스케쥴러의 선택에서 제외
